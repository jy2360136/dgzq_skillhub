## 状态定义

- `equivalent`：必需字段覆盖 ≥80%，且实体代码重合率 ≥80%；无实体列表时仅表示结构和字段等价。
- `partial`：至少有一个关键字段或实体命中，但不能视为完整等价。
- `condition_rejected`：妙想明确标记筛选条件“不采用”。
- `mx_empty`：妙想没有返回可用数据。
- `unsupported`：字段和实体均未形成有效命中。
- 龙虎榜的字段结构虽能命中，但实体代码重合率为 0，正式判断降为“仅资讯替代”。
