# 国信证券测试结果

## 目录

- `smoke_20261115/`：6 个 Skill 的冒烟输出和错误记录；
- `smoke_20261115/artifacts/`：ETF 筛选和基金对比生成的 Excel/TXT；

## 已确认

- ETF 筛选可稳定生成 Excel/TXT；
- 财务数据冒烟可返回真实三表；
- 行情数据冒烟可返回真实个股行情；
- 宏观数据大部分指标可返回，LME 铜查询出现过超时；
- 智能选股返回指标数组，但股票代码/名称配对不清晰；
- 基金对比多次返回“未能获取任何基金数据”。

## 与批量测试的关系

`04_测试结果/广发国信联合benchmark/` 保存 50 题级汇总。本目录保留更细的单次冒烟输出和生成文件，便于解释限额、超时和输出形态问题。

本项目不保存国信 API Key。复跑时从 `GS_API_KEY` 用户环境变量读取。
