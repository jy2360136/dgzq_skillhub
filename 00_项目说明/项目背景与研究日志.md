## 1. 项目背景

### 1.1 业务背景

东莞证券 AI 创新开发部门计划建设面向 C 端用户的 AI Skill 广场，首期准备提供 6 个 Skill，让用户能够查询、筛选、分析和下载使用。

部门当前存在两个现实条件：

1. 自研 AI 能力相对有限，需要优先复用成熟数据能力；
2. 东莞证券已与东方财富妙想 MCP 合作，可以较充分地调用妙想的数据接口。

因此项目不是从零训练模型，而是要做三件事：

- 调研金融机构已经推出的 Skill 及其真实功能边界；
- 判断哪些能力可以由妙想 MCP 直接实现，哪些需要在 Skill 层二次计算；
- 从行业共识、用户价值和可交付性出发，确定东莞证券首期 6 个 Skill。

### 1.2 项目最初的问题

交接材料中已经有广发、国信等部分 Skill 和测试文件，但存在以下问题：

- 目录含义不清；
- 部分结论是主观相似度，不是可复现测试；
- 本机状态过时，例如曾记录“WorkBuddy 未安装”；
- ETF 200 问只有题目，没有完整执行；
- 官网包与平台安装包没有分开保存；
- 部分 AI 生成结论需要重新核验。

本项目的第一项工作实际上是“交接审计”，而不是直接继续写方案。

## 2. 项目目标

### 2.1 总目标

建设一个仅依赖妙想 MCP 及少量本地计算、但用户可感知效果接近头部券商同类产品的首期 Skill 集合。

### 2.2 “90% 效果”的定义

不使用单一主观相似度，而采用四项验收：

| 维度 | 门槛 |
|---|---|
| 任务完成率 | 同一用例重复执行，至少 90% 返回完整可读结果 |
| 必需字段完整率 | 目标输出模板中的必需字段平均覆盖 ≥90% |
| 结论一致率 | 与竞品同题结果比较，关键结论一致或可解释的样本 ≥90% |
| 格式与合规 | 结论、表格、数据日期、口径、风险提示齐全，符合率 ≥90% |

数据值不要求完全一致。股票池、复权方式、报告期、实时/收盘口径不同，必须在最终回答中明确披露。

## 7. 主要结论

### 7.1 首期 6 个 Skill

1. 市场行情与榜单；
2. 财报透视；
3. 智能选股；
4. ETF 基础筛选；
5. 基金对比与定投；
6. 个股综合分析。

### 7.2 暂不做

- 结构化龙虎榜；
- ETF 资金异动/净申购榜；
- 指数温度体系；
- 最大回撤、夏普比率的原生化筛选；
- 实时盘口和自动盯盘；
- 交易、账户和持仓类能力。

### 7.3 可实现路径

```text
用户自然语言
→ Skill 识别意图和参数
→ 妙想 MCP 取原始数据
→ Skill 层字段归一化和本地计算
→ 固定输出模板
→ 数据日期、口径、风险提示
```

### 8.2 不应该进入仓库的内容

- API Key；
- GitHub Token；
- 登录 Cookie；
- 短信验证码；
- 本地绝对配置路径中的凭证；
- 99_临时文件/。

### 8.3 在另一台电脑继续工作

```powershell
git clone https://github.com/jy2360136/dgzq_skillhub.git
cd dgzq_skillhub
git pull --rebase
```

然后分别在本机配置：

```powershell
[Environment]::SetEnvironmentVariable('EM_API_KEY','<妙想 Key>','User')
[Environment]::SetEnvironmentVariable('SKILLHUB_API_KEY','<中信建投 Key>','User')
```

不要提交这些变量。
