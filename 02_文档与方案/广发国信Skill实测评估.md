# 广发证券与国信证券 Skill 实测评估

> 日期：2026-11-16
> 范围：广发证券 8 个 Skill、国信证券 6 个 Skill，共 700 道正向与边界问题
> 原则：本轮只测竞品；不重复调用妙想 MCP。对妙想的可替代性判断，引用此前中金财富 350 题和妙想专项测试，属于“基于既有实测的能力推断”，不冒充同题一一对比。

## 1. 结论摘要

### 1.1 广发证券

广发 8 个 Skill 的工程稳定性最好：

- 400 次调用中，396 次返回可用内容；
- 4 次空结果均来自 ETF 条件筛选，属于“没有匹配标的”的正常业务结果；
- ETF 榜单、ETF 资金异动、基金详情、基金定投、股票 F10、股票估值、龙虎榜均完成 50/50；
- 输出以结构化 JSON 为主，适合作为产品字段、交互和错误提示设计的基线。

广发能力的可替代性并不相同：

| 能力 | 妙想复刻判断 | 说明 |
|---|---|---|
| 股票估值 | 高 | 行情、PE/PB、财务指标可由妙想获取，历史分位和同业对比由 Skill 层计算 |
| 股票 F10 | 中高 | 公司基本资料可组合获取，但需要统一公司画像模板 |
| ETF 基础榜单/筛选 | 中 | 常见规模、成交额、涨幅可做；回撤、夏普、指数温度等高级筛选不能首期承诺 |
| 基金定投回测 | 中 | 净值序列、基金资料与本地回测可组合，但费率和净值口径需要校验 |
| 基金详情 | 中低 | 妙想对完整基金产品字段覆盖有限，不能承诺等同广发全部字段 |
| ETF 资金异动 | 低 | 妙想当前没有稳定的结构化 ETF 净申购/资金异动能力 |
| 龙虎榜 | 低 | 妙想只能做资讯检索，不能稳定还原营业部、买卖席位和净额结构 |

### 1.2 国信证券

国信 6 个 Skill 的能力方向完整，但本轮稳定性结论需要分层：

| Skill | 本轮实测状态 | 结论 |
|---|---|---|
| ETF 筛选 | 50/50 正常执行并生成文件；48 组有结果、2 组空结果 | 能力强、输出完整，是最值得对标的 ETF 产品 |
| 宏观经济数据 | 49/50 成功，1 次 LME 铜查询超时 | 指标覆盖广，适合机构型数据查询；不属于首期 6 个 C 端优先项 |
| 基金对比 | 50 次中只有 3 组存在生成文件，其余返回“未能获取任何基金数据” | 当前远程数据稳定性不足，不能据 3/50 宣称可稳定复刻 |
| 智能选股 | 50 次均被日限额阻断；此前冒烟返回指标数组 | 可判断接口存在，但不能判断 50 题完整通过率；代码与名称配对仍需验证 |
| 财务数据 | 50 次均被日限额阻断；此前冒烟可返回真实三表 | 妙想对财务数据的既有复刻证据较强 |
| 行情数据 | 50 次均被日限额阻断；此前冒烟可返回真实行情 | 妙想对行情数据的既有复刻证据较强 |

2026-11-16 00:12 再次对国信智能选股、财务数据和行情数据各做一次限额探测，三者仍返回 `197006 超过日限额`。因此这 150 次不计为接口能力失败，也不计为通过。

## 2. 测试方法与状态口径

### 2.1 用例设计

- 广发：8 个 Skill × 50 题 = 400 题；
- 国信：6 个 Skill × 50 题 = 300 题；
- 题型覆盖单字段、多字段组合、不同股票/基金/ETF 对象、日期与报告期变化、分页、排序、阈值、行业/主题、边界日期；
- 每题保存实际命令、标准输出、错误输出、返回数量和生成文件；
- 竞品调用只用于能力评估，不把竞品接口或数据直接用于东莞证券生产环境。

### 2.2 状态定义

| 状态 | 含义 |
|---|---|
| 成功 | 脚本正常退出，返回可读内容或生成有效文件 |
| 空结果 | 接口正常，但没有匹配标的；不等于系统故障 |
| 错误 | 接口报错、超时或没有返回可用业务内容 |
| 日限额 | 账号返回业务限额码，不能据此判断 Skill 本身能力 |

## 3. 广发证券逐项评估

### 3.1 ETF 榜单

- 实测：50/50 成功；
- 覆盖：不同榜单类型、前 N、分页、同指数过滤、连续上涨限制；
- 可返回：代码、名称、涨跌幅、阶段涨幅、换手率、成交额、规模等；
- 产品启示：首期“市场行情与榜单”需要固定榜单类型、字段顺序、更新时间与空榜处理；
- 妙想方案：用行情、指数板块和筛选工具取数，Skill 层统一排序、字段名及日期口径；
- 首期判断：可做，但只承诺已验证榜单，不承诺与广发实时排序完全一致。

### 3.2 ETF 筛选

- 实测：46 成功，4 个条件组合无匹配标的；
- 覆盖：行业/主题、1 月/1 年/3 年收益、回撤、夏普、估值、指数温度、规模、T+0、融资融券和多条件组合；
- 产品启示：竞品的优势在字段全、条件多、筛选与排序一体化，不只是“能查 ETF”；
- 妙想方案：基础字段由妙想筛选，回撤、夏普和历史分位等尽量由本地日频数据计算；
- 首期判断：只做“ETF 基础筛选”；高级风险筛选、指数温度和多条件组合不做强承诺。

### 3.3 ETF 资金异动

- 实测：50/50 成功；
- 覆盖：连续净流入、净流出、净申购、成交额放大等资金异动场景；
- 妙想方案：现有妙想工具没有已验证的 ETF 净申购和异动模型；
- 首期判断：不做。

### 3.4 基金详情

- 实测：50/50 成功；
- 覆盖：基金基本资料、净值与业绩、风险、经理、规模、持仓等多类问题；
- 妙想现状：中金财富基金产品测试中仅 1/50 可等价，27/50 部分可用，22/50 条件未采用或无结果；
- 首期判断：可把“少量核心基金字段”纳入基金对比，但不单独承诺完整基金详情。

### 3.5 基金定投

- 实测：50/50 成功；
- 覆盖：普通定投、指数增强、目标止盈、移动止盈、费用与回撤等组合；
- 妙想方案：获取基金净值与基础资料后，由 Skill 层执行定投现金流和收益回测；
- 首期判断：列入 P1；先支持 1 只基金的普通月定投、累计投入、收益、最大回撤，不承诺竞品全部止盈算法。

### 3.6 股票 F10

- 实测：50/50 成功；
- 覆盖：公司全称、成立日期、经营范围、主营业务、所属行业、上市时间、公司画像等；
- 妙想方案：与财务、估值、新闻和公告工具组合，形成统一公司画像；
- 首期判断：不单列 F10 Skill，纳入“个股综合分析”。

### 3.7 股票估值

- 实测：50/50 成功；
- 覆盖：PE、PB、行业估值、历史分位、ROE、净利率、负债率、现金流、同业对比；
- 妙想方案：估值与财务指标直接取数，历史分位和同业比较本地计算；
- 首期判断：高可替代，纳入“财报透视”和“个股综合分析”。

### 3.8 龙虎榜

- 实测：50/50 成功；
- 覆盖：指定日期/市场榜单、上榜原因、营业部、买卖席位、净额等；
- 妙想现状：在已有 50 题中只能提供资讯性描述，不能结构化还原席位榜；
- 首期判断：不做结构化龙虎榜。

## 4. 国信证券逐项评估

### 4.1 ETF 筛选

- 实测：50/50 正常执行，50 组均生成至少一个文件；48 组有 ETF 结果，2 组为空结果文件；共 98 个 TXT/XLSX；
- 覆盖：股票型、债券型、商品型、跨境型、货币型、REITs 等类别，以及成交额、规模、T+0、融资融券、收益、回撤、夏普和热度等条件；
- 输出启示：C 端不能只返回一句结论，应同时提供主表、差异说明和可下载文件；
- 首期判断：国信是 ETF 首选产品对标；我方首期只承诺基础筛选，并逐步补风险指标。

### 4.2 宏观经济数据

- 实测：49/50 成功；LME 铜查询 1 次超时；
- 覆盖：GDP、CPI、商品、行业等宏观/产业数据；
- 产品启示：国信的 API 数据面很宽，但 C 端 Skill 广场首期更需要高频、短链路场景；
- 首期判断：不占用首期 6 个名额；后续可作为“宏观数据查询”或机构版能力。

### 4.3 基金对比

- 实测：3/50 有生成文件，47/50 返回“未能获取任何基金数据”；
- 风险：基金代码解析、远程数据源稳定性和错误提示均不满足生产要求；
- 产品启示：不能把 3 个冒烟样本的字段完整度外推为 50 题通过率；
- 首期判断：基金对比仍列入 P1，但先按我方口径自建，不按国信当前接口的稳定性承诺。

### 4.4 智能选股

- 批量：50/50 被日限额阻断；
- 冒烟：可返回指标数组，但股票代码/名称配对不清晰，不能直接形成 C 端表格；
- 妙想方案：`mx_stocks_screener` 已具备 PE、PB、ROE、增长、行业、主题、涨跌、成交额、换手率等筛选；
- 首期判断：列为 P1；由 Skill 层做条件拆解、字段补全、代码名称校验和 Top N 排序。

### 4.5 财务数据

- 批量：50/50 被日限额阻断；
- 冒烟：可返回真实资产负债表、利润表、现金流数据；
- 妙想既有实测：中金财富财务 50 题中 44 题可等价、6 题部分可用；
- 首期判断：列入 P0，由妙想提供三表与核心指标，Skill 层统一报告期、同比和单位。

### 4.6 行情数据

- 批量：50/50 被日限额阻断；
- 冒烟：可返回真实个股行情；
- 妙想既有实测：中金财富行情 50 题中 35 题可等价、10 题部分可用、5 题条件不采用；
- 首期判断：列入 P0，但只承诺已验证的个股、指数、ETF 行情和常见榜单。

## 5. 对妙想 MCP 的可替代性判断

以下判断同时使用本轮广发/国信实测、此前中金财富 350 题和妙想专项测试。由于本轮未重复调用妙想，因此不是严格的同题 A/B，而是“能力证据 + 工程可行性”的产品判断。

| 能力簇 | 首期是否纳入 | 妙想直接能力 | 需要 Skill 层补齐的内容 | 风险等级 |
|---|---|---|---|---|
| 个股/指数/ETF 行情与常见榜单 | 是 | 高 | 日期口径、榜单排序、字段统一 | 低 |
| 三表、核心财务指标、估值 | 是 | 高 | 报告期统一、同比、行业对比、单位 | 低 |
| 基础智能选股 | 是 | 中高 | 条件拆解、字段补全、代码名称校验 | 中 |
| ETF 基础筛选 | 是 | 中 | 规模/成交额/收益条件归一化、固定模板 | 中 |
| 基金对比与定投 | 是，P1 | 中 | 基金代码校验、净值序列、费用和回测算法 | 中高 |
| 个股综合分析 | 是，P1 | 中高 | 聚合行情、财务、估值、新闻、公告和同业 | 中 |
| 完整基金产品详情 | 否 | 低到中 | 大量字段需逐项验证 | 高 |
| ETF 资金异动/净申购 | 否 | 低 | 缺少结构化数据与异动模型 | 高 |
| 结构化龙虎榜 | 否 | 低 | 仅有资讯，无法还原席位与净额 | 高 |
| 实时盘口、盯盘、交易 | 否 | 低 | 数据频率、账户与合规条件不满足 | 极高 |

## 7. “90% 效果”的落地方式

首期不以“底层字段全部相同”为目标，而是同时满足：

1. 任务完成率 ≥90%；
2. 必需字段完整率 ≥90%；
3. 关键业务结论一致或可解释率 ≥90%；
4. 数据日期、口径、缺失字段和风险提示齐全率 ≥90%。

多字段问题不要求妙想一次原生返回全部字段。允许 Skill 层把一个复合问题拆成多个 MCP 调用，再合并、计算和渲染；但必须保证：

- 每个字段都有数据来源；
- 不同日期的数据不能混成同一时点；
- 本地计算字段明确标注算法；
- 没有数据的字段明确显示缺失，不能用模型常识补造。

## 8. 风险与限制

- 竞品 API 的授权范围仅用于调研和评测，不建议直接用于对外生产，也不应转售竞品数据。
- 广发 4 个 ETF 空结果不是故障；统计时不能把它们并入系统错误。
- 国信 150 次限额不能解释为接口失败；国信 47/50 基金对比无数据则是明确的业务可用性风险。
- 本轮每家 50 题，满足用户要求的下限，但还不是 100 题压力测试；稳定性验收仍需次日补齐限额用例并连续复跑。
- 本轮没有重复调用妙想，因此“高/中/低”是产品可替代性判断，不是严格的同题相似度分数。
