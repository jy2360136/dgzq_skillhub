## 2. 广发 Skill 的真实做法

广发包结构非常轻：

```text
SKILL.md
references/*.md
scripts/cli.py
scripts/gf_client.py
```

本质是：

```text
自然语言
→ 模型识别任务
→ 从问题中抽取结构化参数
→ 本地 CLI
→ 带 API Key 调用统一网关
→ 获取 JSON
→ 按输出规范总结
```

统一网关：

`POST https://mcp-api.gf.com.cn/gf-skills/skills/mcp/call`

请求体：

```json
{
  "service_name": "etf_search",
  "tool_name": "finance_api_inclusive_etf_list_get",
  "args": {}
}
```

广发值得学习的地方：

1. 一个 Skill 对应一个清晰业务任务，不按后端接口机械拆分。
2. SKILL.md 同时承载触发词、能力边界、参数、错误恢复和输出规范。
3. 多个 Skill 共享 API Key、统一网关和调用客户端。
4. 用渠道参数和注册链接做增长归因。
5. 输出规范强制“结论优先、关键字段、风险提示、数据来源”。

## 3. 妙想 vs 广发：局部样例判断

| 能力 | 旧版局部样例分 | 复核结论 |
|---|---:|---|
| 股票 F10 / 公司简况 | 95% | 主体字段可接近一致，不作为全量数值一致率 |

## 4. 关键实测结论

### 4.1 几乎可以复刻

- **股票 F10**：公司全称、板块、上市日期、行业、经营范围均可返回。
- **财务对比**：营收、净利润、ROE、净利率、负债率、现金流等可以返回；部分数值和同比口径与广发有差异。
- **基金定投计算器**：这是最成功的复刻案例。妙想单次最多约 3 年日度净值，分三段取数后本地回测，结果与广发仅差约 8.36 元。

### 4.2 形态可以相似，但结果不完全一致

- **ETF 榜单**：两边都能返回涨幅榜，但妙想包含科创200ETF，广发未包含，说明 ETF 池不同。
- **ETF 筛选**：两边都能按“行业 + 近1月涨幅 + 排序”返回结果，但广发命中影视/消费，妙想命中机器人。
- **基金产品信息**：核心字段可复刻，但广发“当前基金规模”和妙想“中报资产总计”不是同一指标。

### 4.3 不能直接复刻

- **龙虎榜**：妙想只有新闻检索，无法返回完整结构化上榜清单。
- **ETF 资金异动**：妙想可返回份额变化排名，但没有“大幅/持续流入流出”模型和逐日资金明细。

## 8. 当前最重要的产品判断

东莞证券不需要复制广发的“8 张卡片”才能开始。

更合理的路径是：

> 用妙想 MCP 快速做出 6 个行业共识高、结果稳定的 Skill，先把用户、调用量、权限、审计和运营跑通；再用研报公告、宏观数据和自研指标做差异化。

如果追求“每一个数字都与广发一致”，必须补齐：

- 交易所级龙虎榜结构化数据
- ETF 净申购和资金异动专有数据
- 统一的估值温度、指数温度、夏普、最大回撤计算口径
- 更稳定的参数化 ETF 筛选接口
