# 中金财富 Skill 与东方财富妙想 MCP 能力对比

> 测试时间：2026-11-15  
> 中金财富入口：https://web.ciccwm.com/zzt/app/skills-center/#/  
> 测试方式：直接执行中金财富 Skill 脚本 + 直接调用妙想 MCP，不使用 Computer Use 逐题操作。  
> 用例规模：350 道正向问题，6 个 Skill 各 50 题，其中 ETF 热榜 100 题。

## 1. 结论摘要

| 中金财富 Skill | 50 题中的可等价结果 | 部分可用/需拆分 | 条件不采用 | 空结果 | 不支持 | 判断 |
|---|---:|---:|---:|---:|---:|---|
| 行情数据 | 35 | 10 | 5 | 0 | 0 | 高可替代 |
| 财务数据 | 44 | 6 | 0 | 0 | 0 | 高可替代 |
| ETF 热榜 | 35 | 8 | 57 | 0 | 0 | 有限可替代 |
| 热榜资讯 | 50 | 0 | 0 | 0 | 0 | 结构可替代 |
| 龙虎榜 | 0 | 50 | 0 | 0 | 0 | 仅资讯替代 |
| 基金产品 | 1 | 27 | 0 | 7 | 15 | 低可替代 |

总体判断：

- 妙想可以直接支撑中金财富的行情快照、历史行情、A 股财务主要指标和新闻资讯。
- ETF 热榜不能整体替代。涨幅方向表现很好，但资金榜、特色榜、热搜榜和多字段组合被大量条件拒绝。
- 中金财富龙虎榜有结构化榜单与席位明细，妙想只能检索相关新闻，实体代码重合率为 0，不能当作等价替代。
- 基金产品是最明显的组合能力缺口：妙想能返回部分档案、规模、持仓或业绩字段，但一次问多个字段时经常只返回其中一部分，必须由 Skill 层拆分调用。

## 2. 测试方法

### 2.1 题目设计

总计 350 道正向问题：

- 行情数据：50 题；
- 财务数据：50 题；
- ETF 热榜：100 题；
- 热榜资讯：50 题；
- 龙虎榜：50 题；
- 基金产品：50 题。

问题覆盖：

- 单字段；
- 多字段；
- 多字段顺序；
- 多周期；
- 多榜单；
- 多证券；
- 多基金；
- 多股票财务表；
- 代码 + 名称 + 指标组合；
- ETF 涨跌幅 + 成交额 + 换手率 + 溢价率 + 总市值 + 跟踪指数等组合。

### 2.2 执行方式

中金财富：

```text
问题 → 映射到官方脚本参数 → Python 脚本直接调用中金财富接口
```

妙想：

```text
同一自然语言问题 → 对应妙想 MCP 工具 → 保存原始表格和条件采用标记
```

不使用 Computer Use 解决逐题操作效率问题。

### 2.3 判定规则

- **可等价**：必需字段覆盖率 ≥80%，实体代码重合率 ≥80%。
- **部分可用/需拆分**：至少命中一个关键字段或部分实体，但不能完整等价。
- **条件不采用**：妙想返回了数据，但明确标记用户条件“不采用”。
- **空结果**：妙想未返回可用数据。
- **不支持**：字段和实体均没有有效命中。

注意：新闻资讯没有结构化实体代码，因此这里的“可等价”只表示结构和字段等价，不表示新闻标题、排序、来源完全相同。

## 3. 行情数据

50 题结果：

- 35 题可等价；
- 10 题部分可用；
- 5 题被条件拒绝。

表现较好的字段：

- 最新价、涨跌幅、成交额、成交量；
- 换手率、总市值、PE、PB；
- 历史开盘、最高、最低、收盘；
- 行业、概念、地域板块；
- A 股、创业板、ETF 涨幅/跌幅榜单；
- 单只股票的资金流入、流出和主力净流入。

主要差异：

- 中金财富资金流是分档/分时结构，妙想通常返回表格化汇总，需要归一化。
- 中金财富“资金流入、流出、成交额、换手率”可以一次脚本调用，妙想在多字段问法下有时只返回主力净流入。
- 证券名称、板块名称和单位存在差异。

建议：行情 Skill 可首期上线，但资金流部分应拆成“行情字段”和“资金流字段”两次调用，再在 Skill 层合并。

## 4. 财务数据

50 题结果：

- 44 题可等价；
- 6 题部分可用；
- 0 题空结果或协议失败。

覆盖：

- 主要财务指标；
- 利润表；
- 现金流量表；
- 资产负债表；
- 多期年报、中报和一季报；
- 多股票财务横向比较；
- 多表组合查询。

表现较好的字段：

- 营业收入、净利润、ROE、毛利率、净利率；
- 总资产、总负债、资产负债率；
- 经营现金流、投资现金流、筹资现金流；
- 存货、应收账款、货币资金。

主要差异：

- 中金财富返回英文/内部字段名更多，妙想返回中文表格标题；
- 报表期口径和单季度/累计口径需要统一；
- 多表一次问询时，妙想有时不返回全部表，需要按“指标 → 利润表 → 现金流 → 资产负债表”逐项调用。

建议：财务透视可作为首期核心 Skill之一；采用固定字段模板、固定调用顺序和多表合并，不依赖一次自然语言问句返回所有字段。

## 5. ETF 热榜

100 题结果：

| 子类 | 题数 | 可等价 | 部分可用 | 条件不采用 |
|---|---:|---:|---:|---:|
| 涨幅榜 | 25 | 24 | 0 | 1 |
| 跌幅榜 | 10 | 0 | 8 | 2 |
| 资金榜 | 15 | 0 | 0 | 15 |
| 特色榜 | 12 | 0 | 0 | 12 |
| 热搜榜 | 3 | 0 | 0 | 3 |
| 多字段组合 | 35 | 11 | 0 | 24 |

结论：

- **涨幅榜是最稳定的能力**，Top 10/20/50/80、5 日/20 日/60 日/今年以来涨幅榜的代码重合率很高。
- 跌幅方向只能做部分近似，妙想经常仍返回涨幅榜或忽略“跌幅”条件。
- 主力净额、申购净流入、融资净流入等资金榜不稳定。
- 连涨、换手、溢价、自选、热搜等特色榜大量条件被拒绝。
- 多字段组合超过一半被“不采用”，说明妙想不能把“榜单条件 + 多个展示字段 + 排序”稳定解析为一次请求。

建议：

1. 首期 ETF Skill 只承诺“涨幅榜 + 代码/名称/涨跌幅/成交额/规模/换手率”等基础字段；
2. 资金榜、特色榜、热搜榜不进入首期；
3. 多字段需求由 Skill 层拆成“榜单调用 + 明细补全调用”，不要要求一次自然语言调用完成所有字段；
4. 如果要与竞品完全一致，需要补 ETF 专用结构化筛选/榜单接口。

## 6. 热榜资讯

50 题结构命中率为 100%，但这只代表：

- 可以返回新闻标题；
- 可以返回来源；
- 可以返回发布时间；
- 可以返回摘要或主题分类；
- 可以按资讯类型和专题查询。

不能代表：

- 与中金财富的新闻源完全相同；
- 与中金财富的排序完全相同；
- 同一条新闻的正文完全一致；
- 可以替代持牌机构对资讯内容的审核责任。

建议：资讯 Skill 可以作为“资讯摘要”能力上线，但不能宣传为“中金财富同榜单”。

## 7. 龙虎榜

50 题结果：

- 中金财富 50/50 成功；
- 妙想 50/50 能返回龙虎榜相关新闻或部分字段；
- 但结构化实体代码重合率为 0；
- 上榜原因、买卖席位、营业部明细、净买入结构不能稳定等价。

判断：**不能做结构化龙虎榜首期替代**。

可用降级：做“龙虎榜资讯摘要”，明确并不是交易所级结构化榜单；或者等待妙想补结构化龙虎榜接口。

## 8. 基金产品

50 题结果：

- 1 题可等价；
- 27 题部分可用；
- 15 题不支持；
- 7 题空结果；
- 0 题妙想协议错误。

主要原因：

- 中金财富支持按名称模糊搜索、内部 product_id、档案、费率、持仓、业绩、分红、公告和基金对比；
- 妙想基金接口对基金代码或产品标识更敏感，名称搜索和产品实体映射不稳定；
- 一次询问多个基金字段时，妙想经常只返回其中一个字段块；
- 基金持仓、费率、分红和公告的返回结构差异较大。

建议：

1. 首期基金 Skill 以“基金代码 + 基础档案 + 规模 + 经理 + 净值 + 阶段收益”为范围；
2. 不支持名称模糊搜索时先由本地产品字典或代码搜索服务做实体归一化；
3. 基金对比按代码逐只查询，再由 Skill 层对齐字段；
4. 费率、持仓、分红和公告作为二期能力，不承诺一次自然语言问句全返回。

## 9. 多字段组合能力判断

这是本轮测试最重要的结论之一。

妙想支持多字段，但不是所有字段都能在自然语言触发中被完整解析：

- A 股行情：多数可以通过一次或少量调用返回；
- 财务数据：按表拆分后较稳定；
- ETF 榜单：条件 + 排序 + 多字段组合稳定性明显不足；
- 基金产品：多字段一次返回覆盖低；
- 龙虎榜：没有结构化底层，任何多字段都无法等价。

因此不建议立即把“妙想必须原生支持所有多字段一次性返回”作为首期验收条件。更合理的工程方案是：

```text
用户问题
→ Skill 解析目标实体和字段
→ 按字段组拆分妙想调用
→ 合并结果
→ 统一模板输出
```

只有当多个头部竞品都稳定支持同一复杂组合，而拆分调用导致明显体验或成本问题时，才应把“原生多字段一次返回”反馈给妙想作为接口需求。

## 10. 首期产品建议

建议首期上线或保留：

- 行情数据基础字段；
- 财务透视；
- 新闻资讯摘要；
- ETF 涨幅榜和基础字段；
- 基金代码查询与基础档案。

不建议首期上线为等价能力：

- ETF 资金榜、特色榜、热搜榜；
- 结构化龙虎榜；
- 基金费率、持仓、分红、公告的完整多字段查询；
- 多基金复合推荐。
