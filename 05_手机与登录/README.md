# 安卓手机与验证码操作能力评估

## 当前实测状态

- 已安装官方 Android Platform Tools
- ADB 路径：`05_手机与登录/platform-tools/adb.exe`
- ADB 版本：1.0.41 / Platform Tools 37.0.1
- 已执行 `adb kill-server`、`adb start-server`、`adb devices -l`
- 当前结果：设备列表为空，没有出现 `device` 或 `unauthorized`
- Windows 当前也没有识别到 Android/MTP/ADB USB 设备
- 结论：手机尚未被电脑识别，还不能读取验证码

## 能否操作安卓手机

可以，推荐使用 **ADB + 截图/UI 层级 + 文本输入**，不是 Windows Computer Use。

可用能力：

- 唤醒手机
- 点击、滑动、输入文本
- 截图并识别验证码
- 读取当前界面控件树
- 打开指定 App
- 从通知栏读取短信验证码（前提是系统允许 ADB 读取通知）
- 在浏览器中填写手机号和验证码

限制：

- App 可能禁止截屏或 ADB 输入
- 验证码可能只在通知栏显示
- 图形验证码、滑块、人脸识别需要人工处理
- 不应绕过平台风控或服务协议

## RSA 授权怎么开启

RSA 授权不是手机里的一个“模式开关”，而是首次连接时手机弹出的调试授权确认框。

正确步骤：

1. 使用支持数据传输的 USB 线，不要用只能充电的线。
2. 手机设置 → 开发者选项 → 打开“USB 调试”。
3. 连接电脑，解锁手机。
4. 下拉通知栏，把 USB 用途改为“传输文件 / MTP”。
5. 手机上出现“允许 USB 调试吗？”时勾选“始终允许使用这台计算机进行调试”，点击“允许”。
6. 电脑运行：

```powershell
.\05_手机与登录\adb_check.ps1
```

7. 如果仍显示空列表：
   - 开发者选项 → 撤销 USB 调试授权
   - 拔掉数据线重新连接
   - 再次在手机上确认 RSA 指纹弹窗
8. 如果 Windows 仍然没有识别手机：
   - 换一根数据线或换 USB 口
   - 安装手机品牌对应的 Windows USB 驱动
   - 关闭再重新打开 USB 调试

如果 `adb devices` 显示 `unauthorized`，表示电脑已经识别到手机，但手机还没有点“允许”。

## 安全边界

- 不批量读取短信收件箱
- 不导出通讯录、照片、聊天记录
- 不记录验证码到项目文件
- 只处理当前目标机构的登录验证码
- 登录动作需要用户明确授权
- 遇到风控或验证码时暂停并交给用户处理
