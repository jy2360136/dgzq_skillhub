## 2. 对东莞证券的直接启示

1. 平台内分发已经是现实渠道，官网下载不是唯一形态。
2. 大多数机构采用“业务 Skill + 机构统一 API Key + 网关”的结构。
3. 只包装一个自然语言入口不够，必须同时提供：
   - 触发词与不适用场景；
   - 结构化输入参数；
   - 字段归一化；
   - 固定输出模板；
   - 失败与鉴权处理；
   - 风险提示和合规边界。
4. 盘口、模拟交易、账户、实时盯盘等能力依赖专有实时数据，妙想并不能天然替代。
5. 东莞证券首期应优先做基础数据 + 分析工作流，不宜先从交易或实时盯盘切入。

## 3. 研究边界

- 本表来自 WorkBuddy 界面可见结果，部分卡片没有展开详情。
