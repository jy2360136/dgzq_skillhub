4. 大盘分析
5. 盘口异动
6. 个股综合分析

8. 智能选股

## 3. 渠道平台

### 腾讯 WorkBuddy

- 金融版已上线 80+ 金融专属专家、专家团与技能
- 中信建投、广发证券等机构已入驻
- 使用方式：技能广场搜索机构名称，手机号注册，选择安装
- 对东莞证券的意义：可作为外部分发渠道，不必只做自有网页

### 扣子（Coze）

- 支持技能商店搜索、一键添加
- 对东莞证券的意义：适合快速验证 C 端需求和流量

### 同花顺

- 已出现“Skill 广场 + MCP 广场”双平台协同的产品形态
- 目前公开信息较多但官方页面仍需进一步验证
- 对东莞证券的意义：金融数据和流量入口型竞品，不只是券商 Skill

## 4. 结论

当前行业不是统一走向“可下载 ZIP”，而是分成四种形态：

1. 广发式：ZIP + API Key + 本地 CLI
2. 中信建投/国信式：平台内一键添加
3. 华泰/中金/中金财富/平安式：App 内嵌 Skill
4. 国泰海通式：机构投研平台内专项 Skill

因此，东莞证券不应该只做“下载 ZIP”一种形态，而应该同时支持：

- 网页 Skill 广场展示
- MCP / 平台内一键连接
- 可选的本地 Skill 包
- 机构客户私有部署
