# 中信建投 vs 妙想：沪深300估值实测

> 测试时间：2026-11-15  
> 标的：沪深300指数（000300.SH）  
> 目的：验证妙想 MCP 经过字段归一化和本地百分位计算后，能否达到中信建投同类 Skill 的用户效果。

## 1. 双方原始结果

|---|---:|---:|---:|

数据时点：

- 中信建投：接口更新 2026-11-15 04:20:57，底层行情日 2026-11-13。
- 妙想：最新行情日 2026-11-13。

## 2. 百分位计算口径

中信建投的 5 年 PE/PB 百分位来自其 `valuation` 接口，样本区间为 2021-11-15 至 2026-11-13，共 406 个采样点。

妙想返回了 2021-11-15 至 2026-11-13 的 1212 个日频 PE/PB 点。为了做同口径比较，在中信建投测试目录之外使用妙想原始日频序列计算：

```text
percentile = count(历史值 <= 当前值) / 历史样本数
```

计算结果：

- PE：13.44，历史样本 1212，最小值 10.31，最大值 14.93，百分位 74.01%。
- PB：1.328，历史样本 1212，最小值 1.138，最大值 1.747，百分位 34.08%。

## 3. 结论

这组用例可以达到中信建投的效果：

- PE、PB 当前值几乎一致；
- 1 年最大回撤几乎一致；
- 5 年百分位差异小于 3.1 个百分点；
- 输出结构、数据日期和口径均可等价表达。

但不能直接说“妙想原生支持 5 年历史百分位”：

- 妙想的自然语言接口默认返回 3 年 PE 百分位等现成字段；
- 5 年百分位需要拉取日频估值序列后在 Skill 层计算；
- 因此这类能力应定义为“妙想数据 + 本地指标计算”，而不是“妙想原生指标”。

## 4. 对首期产品的意义

`个股综合分析`、`ETF 基础筛选`、`市场行情与榜单` 可以复用这套方式：

1. 妙想负责取行情、估值、财务和新闻原始数据；
2. Skill 层统一日期、字段和复权口径；
3. 本地计算百分位、最大回撤和定投收益；
4. 输出固定模板与口径说明。

这类实现足以达到用户可感知的 90% 效果，但必须明确披露“部分指标由本地计算”。
