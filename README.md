# 东莞证券 AI Skill 广场竞品调研

> 调研周期：2026-11-13 至 2026-11-16
> 目标：收集金融机构对外 AI Skill，验证东方财富妙想 MCP 能否达到竞品约 90% 的用户效果，并确定东莞证券首期 6 个可上线 Skill。

## 1. 项目结论

首期建议提供 6 个 Skill：

| 优先级 | Skill | 首期判断 |
|---|---|---|
| P0 | 市场行情与榜单 | 妙想覆盖高，优先上线 |
| P0 | 财报透视 | 妙想财务实测强，优先上线 |
| P0 | ETF 基础筛选 | 可做基础范围，不承诺高级风险筛选 |
| P1 | 个股综合分析 | 多源组合后上线 |
| P1 | 智能选股 | 由妙想筛选工具 + Skill 层条件解析实现 |
| P1 | 基金对比与定投 | 谨慎上线，先控制基金字段与净值口径 |

首期明确不做：结构化龙虎榜、ETF 资金异动/净申购、实时盘口、完整基金费率与持仓、交易账户能力。

“达到竞品 90% 效果”采用四项可验收指标：

- 任务完成率 ≥90%；
- 必需字段完整率 ≥90%；
- 关键业务结论一致或可解释率 ≥90%；
- 数据日期、口径、缺失说明和风险提示完整率 ≥90%。

## 5. 最重要的能力边界

### 可以重点做

- 个股、指数、ETF 常见行情；
- 三表、财务指标、估值和历史分位；
- 常见条件选股；
- 基础 ETF 筛选；
- 基金对比与普通定投的受控版本；
- 个股综合分析和公司画像。

### 不能直接承诺

- 与竞品完全相同的 ETF 池、排序和实时字段；
- 最大回撤、夏普、指数温度的稳定原生化筛选；
- 结构化龙虎榜和 ETF 净申购榜；
- 完整基金费率、持仓、分红；
- 实时盘口、自动盯盘和交易账户能力。

多字段问题允许 Skill 层拆成多次 MCP 调用，不要求妙想原生一次返回全部字段。关键是不能混用日期、补造缺失字段或隐藏计算口径。

## 6. 复现方法

### 6.1 妙想 MCP

按 `01_竞品Skills/东方财富妙想/docs/` 中的安装说明配置。Key 只保存在当前用户环境变量，不写进仓库。

### 6.2 广发与国信批量测试

```powershell
$env:GF_SKILLS_APIKEY=[Environment]::GetEnvironmentVariable('GF_SKILLS_APIKEY','User')
$env:GS_API_KEY=[Environment]::GetEnvironmentVariable('GS_API_KEY','User')
$env:COZE_GUOSEN_API_KEY_7627056463827140634=$env:GS_API_KEY
$env:COZE_GUOSEN_API_KEY_7627085587157205043=$env:GS_API_KEY

python tools/run_gf_gs_batch.py --workers 4
python tools/summarize_gf_gs_batch.py
```

国信日限额恢复后补跑：

```powershell
python tools/run_gf_gs_batch.py --only-skill 智能选股 --workers 2 --merge
python tools/run_gf_gs_batch.py --only-skill 财务数据 --workers 2 --merge
python tools/run_gf_gs_batch.py --only-skill 行情数据 --workers 2 --merge
python tools/summarize_gf_gs_batch.py
```

批量脚本生成的问题命令使用 `<GS_API_KEY>` 占位，只在运行时从环境变量替换，日志会再次脱敏。

## 7. 安全规则

- 不把 API Key、GitHub Token、Cookie、验证码写入仓库；
- Key 只放当前用户环境变量或本机密钥管理；
- 不提交手机通信内容和登录页面凭据；
- 竞品 Skill 先检查再执行；
- 竞品数据和接口仅用于调研评测，不作为东莞证券生产数据源；
- 所有结论必须能回溯到原始响应或明确标注为推断。
