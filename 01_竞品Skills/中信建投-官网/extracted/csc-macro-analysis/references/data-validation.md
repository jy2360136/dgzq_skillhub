# 数据核验清单

生成报告前核验。未通过的数不进报告，或显式标注。

## 字段与标的

- 字段名来自 `datas` 行的键。
- `rich_text` 做过纯拼接，没有按文本去重。
- `total_rows ≤ 1` 的组件已当作不可得。
- 返回体代码和名称与问题一致。NLU 不一致不是重问理由。
- 含个股字段的返回已整条作废。
- 每个数值都有起止日期。近 N 日或近 N 月没有丢首日。

## 风格

- 相对收益的基准是沪深300，不是两条风格指数直接相减后冒充超额。
- 中证2000、国证成长、国证价值没有被拿来代理。
- 5日和20日相对收益为正且相邻窗口保持相对优势时，判定层标阶段性占优；但**报告层不写「阶段性占优」「短期强势」**，概述只做方向陈述。只有单日领先时同样不写。窗口方向不一致时，该轴内部记「大小盘不突出」或「红利与科创不突出」，两轴都不一致时记「当前风格不突出」，该状态词不进报告。报告写概述、相对收益表。估值分位、成交占比、换手分位不可得时不写「拥挤」，也不写成不拥挤或不过热。
- 内部逐项记录已成立、已核验但不成立、未获取到。数据缺口点名一次。
- 广度、换手、均线未获取到时不因此改判。只有文字描述的窗口没有被标成阶段性占优，概述和轮动句里没有提该窗口。

## 主线

- 候选同时看了近一周和近一月，不是只看一日涨幅榜。
- 主线候选满足五项里的四项，且事件逻辑来自已核验事实。
- 未点名候选的资金是 `NA`，不是 0。
- 资金点名用的是指数代码或行业指数，不是概念名。
- 覆盖率低于 80% 时没有总分。

## 事件

- 每条都有日期和来源。旧闻标成历史先例，或已剔除。
- 没有未来日程，没有未宣布政策。
- 没有编造研报机构。

## 出口

- 报告没有偏强、震荡、转弱、情绪阶段、牛市、熊市。
- 逐句过 `references/compliance/compliance-boundary.md` 的三问。
- 免责声明单独成节，为报告最后一节。
