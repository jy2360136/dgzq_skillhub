# 大盘分析输出边界

本文件是合规边界的唯一定义点。判定标准、改写对照和免责文案只在此维护。

适用范围是全部用户可见文本。取数过程不受此约束。免责声明不能治愈违规内容。

## 1. 可输出

- 已发生的风格、行业、概念和事件事实；
- 按固定规则得到的风格状态和主线状态；
- 覆盖率达标时的主线证据评分；
- 条件性传导路径；
- 证据强弱、置信度、反证和失效条件。

## 2. 不可输出

- 大盘研判：偏强、震荡、转弱、情绪阶段、牛市、熊市、指数方向；
- 指数目标点位和确定性涨跌预测；
- “建议买入/卖出”“重点配置”“优先布局”等交易指令；
- 仓位、超配、低配、顺势、等回调、先防守及近义择时表述；
- 把主线评分等同于未来收益；
- 把新闻热度、涨停数量或资金净流入直接写成基本面事实。

## 3. 三问测试

每一句出口前自问，任一命中即不得输出，改写或删除：

| 测试 | 命中特征 |
|---|---|
| 时间指向 | 句子在说将来会发生什么 |
| 宾语指向 | 宾语是用户的买、卖、配置、仓位或择时 |
| 主体指向 | 句子要靠“我们怎么看”才成立 |

## 4. 改写

| 不可输出 | 可输出 |
|---|---|
| 市场偏强，可以顺势 | 删除强弱和操作。改为风格与主线的已核验状态 |
| 风格将切换到成长 | `上证50 在两个窗口由比沪深300更强转为更弱；广度未获取到` |
| 该事件将利好某板块 | `事件事实（日期、来源）。相关概念区间表现为……。实质影响尚未由产业数据验证` |
| 预计下月出台某政策 | `未宣布的政策不列入清单` |
| 主线值得关注 | `状态：主线候选。依据：……。反证：……` |
| 资金面较好 | `净额 +6.4亿；连续净流入 1 天；5 天中 4 天净流入`。写三个数，不写 S、D、P |

## 5. 条件性表达

允许：

```text
若事件影响在行业订单、价格或业绩数据中得到验证，当前催化判断的证据会增加。
```

禁止：

```text
该事件将推动相关板块继续上涨。
```

## 6. 个股

本技能只做到指数和板块。返回的个股名单不得当板块数据。事件事实里的公司名可以出现，不得附带该公司的走势或评价。

## 7. 发布前检查

- 全文没有大盘强弱和情绪阶段；
- 第一节范围说明**只写模板要求的「本报告不做大盘研判」**，不把「市场强弱、情绪阶段、指数方向」等类别逐项列出来当声明——逐项列出会命中上一行的禁用词检查（实测：写成「不输出市场强弱、情绪阶段与指数方向」即触发 `情绪阶段`）；
- 全文没有三问命中的句子；
- 报告层没有「阶段性占优」「短期强势」等阈值型结论（这类结论只留在内部判定）；风格概述只做方向陈述，与内部判定一致；主线候选都能回溯到对应规则；
- 风格节没有「拥挤」「拥挤未评估」「不拥挤」「不过热」。数据缺口点名一次；
- 全文没有证据等级字母 S、A、B，没有文末等级对照；数值后没有（组件）（仅文字）等口径来源标注；只有文字描述的证据没有被标成阶段性占优或市场主线，风格概述和轮动句里没有提该窗口；
- 全文没有 `pct`，没有「超额」「超额收益」「超额变动」，也没有「个百分点」。主线表和风格相对收益表里，涨跌和比沪深300分列；比沪深300用少跌、多跌、多涨、少涨或上涨/下跌对照句，数字不带正负号，后面加 `%`；风格相对收益表默认出现；
- 引用 `references/research/` 里的规则条目时，**规则原文措辞不得直接抄进报告**：例如主线条件 1 的原文含「相对收益」四字，直接引用会命中本节禁用词，须按报告层措辞改写为「两个窗口均比沪深300 更强」。自检脚本命中后逐处改写；
- 免责声明单独成节，为报告最后一节「七、免责声明」，报告到此结束；正文只原样照抄 §8，不增删、不改写、不换标点，不并入「数据来源与限制」，也不把第一节范围说明或其他句子写入本节。

## 8. 免责文案

报告中单独作为「七、免责声明」，不并入「数据来源与限制」。报告到此结束。
