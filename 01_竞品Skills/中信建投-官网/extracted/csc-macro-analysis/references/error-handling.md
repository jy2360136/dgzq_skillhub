# 错误处理

鉴权与配额不走降级：未配置 `CSC_SKILLHUB_API_KEY`，或返回 401、403、`MISSING_API_KEY`、`INVALID_API_KEY`、429、quota exceeded，立即终止，返回 `SKILL.md` 的引导提示，并补一句原因。不重试，不换数据源。

## 取数失败

`30004`、连接错误或空组件：问法改得更口语，重试 1 次。仍失败则该项记不可得。不得为同一指标反复换问法。

## 缺失后仍然要写的内容

| 缺失 | 报告里怎么写 |
|---|---|
| 某条风格指数 | 该轴写“未获取到”，不用别的指数替代 |
| 概念排名 | “候选池未建立”加原因。已核验事件点名的板块仍可列出，状态最高到“逻辑验证不足” |
| 资金序列 | 写「资金序列未获取到」。不写 `NA`。不影响其他已满足条件的陈述，不能靠 `rich_text` 里的一句话净额升级主线 |
| 事件只有散文（`rich_text`） | “未取到可核对的事件数据”，不编造 |

缺失不写成负面，例如不写“资金面存疑”“情绪转弱”。

## 冲突

当前值两次不一致时，第三次取多数。组件与散文冲突时，先对齐窗口，再以组件为准，不在报告中标注。单位统一为亿元，涨跌幅优先用前复权字段。

## 个股字段

返回体出现 `股票简称`、`股票代码` 或 `股票名称`，整条作废。申万一级行业排名是因为问不到结构化行业涨跌幅而禁用；按概念名问资金、以及中证2000 或国证成长，是因为会返回个股或 ETF 字段。

## 范围外问题

- 非 A 股：说明只做 A 股风格、主线和催化。
- 宏观周期或货币政策解读：不在本技能范围。
- 市场强弱、情绪、大盘怎么走：不做大盘研判，改交付风格、主线和催化。
- 要求买卖或仓位：不回答操作，只给已核验的状态。
