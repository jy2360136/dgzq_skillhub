# 基本面与财务分析规则（与数据源无关）

> 本文件定义基本面与财务面的研究方法：如何组织证据、如何检查盈利/成长/现金流质量、如何判断估值指标适用性。**与具体数据源无关**，不包含接口、查询语句或取数纪律；财务数据的查询句式见 `data-source-queries.md`，评分阈值见 `technical-analysis-rules.md` §8.4 与 `scoring.md`。
> **输出措辞约束不在本文件**：所有最终呈现文本一律过 `compliance-boundary.md` 三问测试。

---

## 1. 定位：基本面 ≠ 财务面

- **财务面**回答已经发生的经营结果与财务质量（报表里的数字）
- **基本面对象**还应包括行业位置、竞争格局、业务结构和公司治理（报表外的定性证据）

两者不得混为一谈：财务指标好 ≠ 基本面好（可能是一次性损益），行业景气 ≠ 公司受益（可能份额在流失）。

## 2. 证据四分类（全维度通用标注纪律）

对数据服务返回内容及自身形成的判断，按来源标注四类，**禁止把低等级伪装成高等级**：

| 标签 | 含义 | 示例 |
| --- | --- | --- |
| `RAW` | 原始数据或公开披露事实 | 收盘价、公告原文、财报数值 |
| `PROVIDER_DERIVED` | 数据服务原生计算结果 | 估值分位数、主力净额、技术指标表字段 |
| `SKILL_RULE` | 本 Skill 固定规则计算 | MA 乖离率、IBS、六维评分 |
| `RESEARCH_HYPOTHESIS` | 基于证据形成的待验证解释 | "毛利率下滑可能由原材料涨价驱动" |

输出要求：`RAW` 直出（标来源与日期）；`PROVIDER_DERIVED` 须注明"数据源口径"；`SKILL_RULE` 须挂阈值出处；`RESEARCH_HYPOTHESIS` 按 `compliance-boundary.md` §4A 条件性研究判断条款输出（≤2 条、带反证、标置信度）。

## 3. 研究顺序（不得跳步套阈值）

1. 确认行业分类、主营业务和分析期；
2. 识别收入、利润和现金流的主要来源；
3. 判断行业周期、竞争格局和政策环境；
4. 分析盈利质量、成长质量、偿债和运营效率；
5. 分析估值与市场预期；
6. 检查公告、事件和治理风险；
7. 给出事实、规则状态、条件性解释和待验证事项。

**硬规则**：不得在尚未确认主营业务和行业口径前直接套用财务阈值（§5、§8.4 的阈值均隐含行业适用性前提）。

## 4. 行业与业务分析

至少覆盖（数据可得时）：

- 行业分类及分类来源（申万分类等）
- 公司的产业链位置（上游/中游/下游）
- 收入按产品、地区或业务的结构
- 主要客户、供应商和终端需求
- 行业供需、价格、库存和产能变化
- 竞争格局、市场份额或可比公司
- 政策、监管和技术替代因素

**证据红线**："行业景气"不能仅由行业指数上涨证明；"公司受益"不能仅由概念标签证明——两者都需要业务层面的传导证据（订单、价格、产能利用率等）。

## 5. 盈利质量检查清单

### 5.1 盈利能力

- ROE、ROA、毛利率、净利率及其**连续变化**（单期数值信息量有限）
- 利润增长的来源拆解：收入增长 / 毛利率变化 / 费用率变化 / 投资收益 / 一次性损益
- 归母净利润与扣非净利润的差异（差异大时须点出并说明来源）

### 5.2 成长质量

- 收入增长由什么驱动：销量 / 价格 / 并表 / 会计调整
- 净利润增速是否显著高于收入增速（若无解释来源，视为质量存疑信号）
- 经营现金流是否跟随利润增长
- 应收账款和存货是否同步扩张（扩张快于收入 → 质量存疑）
- 订单、合同或产能是否已经转化为收入和利润

### 5.3 现金流质量

至少比较：

- 经营活动现金流与净利润的匹配度（长期背离是核心红旗）
- 应收账款、合同负债、存货、应付账款的变化方向
- 经营现金流连续为负的原因及可持续性
- 自由现金流仅在资本开支口径完整时计算，否则不输出

**红线**：不得把"净利润增长"直接等同于"经营质量改善"。

## 6. 偿债与运营（按行业适用性选指标）

- 一般行业：资产负债率、净负债率、利息保障倍数、流动/速动比率、应收周转、存货周转、现金转换周期
- 金融行业：资本充足率、不良率、拨备覆盖率、净息差（**资产负债率/流动比率对银行无意义**，按 NOT_APPLICABLE 处理，见 `scoring.md` §4）
- 资源周期行业：现金成本、有效产量、资本开支、项目回报

统一阈值不得跨行业机械套用；指标不适用时记 `NOT_APPLICABLE`，**不得记 0 分**（详见 `scoring.md`）。

## 7. 估值分析

至少说明：

- 指标适用性：PE / PB / PS / EV/EBITDA 各自适用于什么状态的公司
- 当前值、历史分位与口径（注意区分 PB(LF) 与 PB(MRQ)，见 `data-validation.md`）
- **PE 失真场景**：亏损（PE 为负）、周期极端利润位、盈利波动过大 → PE 不参与评分，改用适用指标并标注原因
- 金融、资源、亏损成长公司需要改用什么估值方法
- 估值结论依赖的盈利或现金流假设

"低估/合理/高估"必须绑定指标、时间窗口与固定阈值（如"PE 近三年分位 = X%，按 <30% 偏低阈值属偏低区间"），不得脱离口径单独使用。

## 8. 公司治理与资本运作

核查清单（与事件面联动，证据来源为公告）：

- 控股股东与实际控制人变化
- 股权质押、减持、增持、回购
- 关联交易、担保、资金占用
- 股权激励目标及执行情况（含是否因考核未达标而注销）
- 监管问询、处罚、诉讼、审计意见（非标意见必须单列）
- 再融资、重组、重大投资

**红线**：公告事实与媒体解读必须分开呈现。

## 9. 结论模板

每个基本面/财务结论按以下格式组织（内部结构，输出时按合规条款裁剪）：

```text
事实：<数据或公告显示……>（日期/报告期/来源，RAW/PROVIDER_DERIVED）
规则状态：按固定口径属于……（阈值出处，SKILL_RULE）
解释：可能由……驱动，当前置信度高/中/低（RESEARCH_HYPOTHESIS，按 §4A 输出）
反证：若……出现，则该解释需要下调
缺口：尚缺……数据
```

**禁止**用"质地优秀、成长确定、长期看好"等不可复核评价替代证据（三问测试主体指向违规）。
