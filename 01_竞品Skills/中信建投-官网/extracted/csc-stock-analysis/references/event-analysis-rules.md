# 新闻、公告与事件分析规则（与数据源无关）

> 本文件定义事件面分析的研究方法：从"发生了什么"到"可能通过什么路径影响公司"，以及"为什么涨跌"的异动归因。**与具体数据源无关**，不包含接口、查询语句或取数纪律；取数纪律见 `data-source-queries.md`，事件扫描清单与 query 句式见 SKILL.md Step 2.8。
> **输出措辞约束不在本文件**：所有最终呈现文本一律过 `compliance-boundary.md` 的三问测试；本文件涉及的"候选解释"输出受 §4A「条件性研究判断」条款硬约束。

---

## 1. 证据层级

按可信度从高到低，冲突时优先呈现高等级来源，并保留冲突说明：

1. 公司公告、交易所公告、监管文件；
2. 定期报告、临时报告、正式合同信息；
3. 权威政府、行业协会、监管机构信息；
4. 主流媒体原始报道；
5. 研报观点、访谈、市场传闻。

**硬规则**：

- 传闻不得进入已确认事件结论（只能进"传闻与未经证实信息"栏，标注"未经公告证实"）
- 公告与新闻口径冲突时以公告为准，差异须并列说明
- 引用他人观点（研报/媒体判断）必须标明来源，与本 Skill 的规则化输出**分开呈现**，不得混写

## 2. 事件结构化字段（内部分析用）

每个命中事件在分析阶段至少整理为以下字段（报告中的事件表为其压缩呈现）：

- 事件标题、首次发布时间 / 最新更新时间
- 主体、客体、动作（谁对谁做了什么）
- 事件类型（对照 SKILL.md 2.8.3 的 11 类清单）
- 事实内容（金额、股数、比例等可验证量级）
- 证据来源与证据等级（对照上节 1-5 级）
- 影响方向：利好 / 利空 / 中性 / 待定
- 影响规模、传导机制、持续性（一次性 / 持续性）
- 当前置信度（高 / 中 / 低，定义见 §7）
- 强化条件、失效条件

## 3. 事件传导链

按以下顺序分析，输出"事件 → 传导 → 影响"：

```text
事件事实（L0：日期 + 数值 + 来源）
→ 影响对象（收入 / 成本 / 利润 / 现金流 / 估值 / 情绪）
→ 影响机制（可描述的传导路径）
→ 时间范围（已发生 / 进行中 / 仅有预案）
→ 价格与资金反应（事件窗口内价量表现）
→ 反证与失效条件
```

**必须区分五种状态**，不得混写：

| 状态 | 呈现要求 |
| --- | --- |
| 已发生 | L0 直出，标日期 |
| 已公告但尚未完成 | 注明进度（预案 / 实施中 / 完成） |
| 计划或预案 | 明确标注"预案阶段" |
| 市场预期 | 标注来源，不写成既成事实 |
| 未经证实传闻 | 只进传闻栏 |

**措辞红线**（属三问测试的时间指向类违规）：项目计划不得写成稳定量产；公告金额不得写成已实现收入；行业利好不得直接写成公司利润增加。

## 4. 事件定性、定量与定价判断（对应 SKILL.md Step 3.4）

### 4.1 定性

利好 / 利空 / 中性存疑，判定示例见 SKILL.md 3.4；仅有传闻、无公告佐证的 → "中性存疑"并标注"未经公告证实"。

### 4.2 定量与时效

- 规模：金额 / 股数 / 占股本或市值比例（是否触及"重大"）
- 时点：已发生 / 进行中 / 仅有预案；距今天数
- 持续性：一次性损益（资产处置、政府补助等）不改写长期逻辑，须显式说明

### 4.3 是否已被价格反映（严格判定）

**"已被消化"是有证据门槛的结论**，至少检查以下各项，证据足够才可判定：

- 事件首次传播前后的相对涨跌（个股 vs 行业 vs 指数）
- 事件窗口内成交量与换手率是否异常
- 同行业及高暴露标的的反应（用于剥离行业/市场因素）
- 事件对盈利、现金流或估值的**可量化增量**
- 价格反应是否明显偏离可验证的基本面增量

**判定输出**：

| 证据情况 | 允许的表述 |
| --- | --- |
| 价格反应与可量化增量基本匹配 | `价格反应与事件量级基本匹配` |
| 价格反应明显超出可验证增量 | `存在提前交易迹象，超出部分缺乏基本面增量支撑` |
| 无法量化基本面增量 | `当前无法判断反映程度` |

**禁止**在无法量化增量时写"已经充分兑现""利好出尽"。

## 5. 异动归因（回答"为什么涨跌"）

**触发条件**：用户明确要求归因（"为什么涨/跌"），或当日/近期出现显著异动（如单日涨跌幅、成交额明显偏离近期水平）。未触发时本节省略，不影响六维完整性。

### 5.1 异常确认（先确认"异"再谈"因"）

比较个股与自身历史、所属行业、主要指数，至少覆盖：涨跌幅、振幅、成交额、换手率、发生时点。与历史分布无显著差异的，写"未见显著异动，无需归因"。

### 5.2 四层候选解释（自上而下排查）

| 层 | 排查内容 | 数据依据 |
| --- | --- | --- |
| 市场层 | 指数、风险偏好、流动性 | 三大指数、市场广度 |
| 行业/风格层 | 行业指数、同业同步性 | 行业指数、可比公司当日表现 |
| 公司层 | 公告、业绩、订单、监管、治理事件 | 第五章事件表、公告 |
| 交易结构层 | 前期涨幅、估值位置、资金流、技术位置 | 资金面、关键位、乖离率 |

### 5.3 因果验证（每个候选解释过五问）

1. 信息是否**早于**价格异动（时间先后）
2. 是否产生了新的信息增量（还是旧闻重提）
3. 是否存在可描述的传导机制
4. 高暴露公司是否比低暴露公司反应更明显（横截面佐证）
5. 是否存在同等强度的替代解释

**输出要求**：

- 每个候选解释注明支持证据与不强证据
- 证据不足以确认单一主因时，**必须**输出"存在多个候选原因，当前无法确认单一主因"，并列出候选及各自证据强度——这本身是合格结论，不得强行指定主因
- 禁止仅凭资金流入、主题标签或单条新闻确定因果关系；"主力流入故上涨"属主体指向违规（见 compliance-boundary §4）

### 5.4 候选解释的输出边界

候选解释若要写出"解释 + 传导路径"，按 `compliance-boundary.md` §4A「条件性研究判断」输出：≥2 条 L0 事实支撑、同句写反证/失效条件、标置信度、每报告 ≤2 条。不满足条件的候选解释只在报告内部留档，不输出。

## 6. 事件置信度

| 等级 | 定义 |
| --- | --- |
| 高 | 正式公告或监管文件确认，传导路径明确，有市场或经营数据验证 |
| 中 | 来源可靠，传导合理，但缺少经营结果验证 |
| 低 | 媒体或传闻信息，事实或影响路径不确定 |

**置信度不等于股价方向概率**，输出时不得写成"高置信度利好，股价将……"（时间指向违规）。低置信度事件不进入评分（见 `scoring.md`）。

## 7. 与评分的关系

- 事件与消息面评分按 `scoring.md` §2 与 `technical-analysis-rules.md` §8.6 执行
- 传闻与未经公告证实的内容**不计入评分**，仅以 L0 事实呈现在传闻栏
- 事件置信度只影响事件维度得分的证据权重，不跨维度联动
