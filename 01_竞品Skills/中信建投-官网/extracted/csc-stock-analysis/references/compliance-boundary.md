# 合规边界（唯一定义点）

## 0. 定位与适用范围

- 本文件是 `csc-stock-analysis` 的**合规边界唯一定义点**。判定标准、改写对照、免责文案只在此维护，其他文件一律引用本文件，不得复制粘贴或另立标准。
- **适用范围**：本 Skill 的全部输出——报告正文、章节标题、表格「判断」列、结论句。**取数过程与内部推理不受此约束**，只有最终呈现给用户的文本受约束。报告到免责声明结束，不另附「建议继续提问」或「执行自检（内部记录）」。
- **合规边界不随数据源切换而变**，因此不写在 `data-source-config.md` 中。
- 主 SKILL.md 对本文件的引用方式只有一条铁律（出口必过），不重复本文件内容。

---

## 1. 硬要求

**仅可基于客观数据进行选股，不得出现建议、预测等涉及证券投资咨询牌照的业务内容。**

关键认知：**免责声明不能治愈违规内容**。免责声明是兜底提示，不是合规证明；报告末尾写了"不构成投资建议"，不代表报告正文里的"建议买入"就合规。合规与否只看输出内容本身。

---

## 2. 判定：三问测试

每一句产出在出口前自问三问，**任一命中即判 L2，禁出**：

| # | 测试 | 命中特征 | 典型违规样例 |
|---|---|---|---|
| 1 | **时间指向** | 句子在说将来、说将会发生什么 | "后续有望突破""预计下季度回升""目标价 XX 元" |
| 2 | **宾语指向** | 句子的宾语是**用户的行为**（买/卖/持有/仓位/操作） | "建议减仓""可分批建仓""不建议持有""控制仓位" |
| 3 | **主体指向** | 句子需要注入"我们怎么看"才能成立（主观评价） | "值得长期持有""质地优良""性价比高""推荐" |

> 判定对象是**句子**，不是段落、不是整份报告。一个段落里可以有 L1 句和 L2 句，L2 句单独改写或删除。

---

## 3. 处置：三档

| 档位 | 定义 | 能否输出 | 附加要求 |
|---|---|---|---|
| **L0** | 客观数据：数值、事实、已发生事件、公开披露原文 | ✅ 直出 | 标注来源与日期/报告期 |
| **L1** | 规则化描述：由数据经**固定规则**得出的状态标签 | ✅ 可出 | 必须满足下方三条件 |
| **L2** | 建议 / 预测 / 主观评价 | ❌ 禁出 | 改写为 L1 或删除；改不掉就整句删除 |

### L1 的三个必要条件（缺一即降为 L2）

1. **阈值事先固定**：判定阈值写在本 Skill 的 reference 中（如 `technical-analysis-rules.md`、本文件附表），不是临场拍的
2. **可复现**：同一份输入数据，任何人按规则算出的结果一致
3. **带口径**：输出时标明判定所依据的阈值与数据口径

满足三条 → 该描述是"规则的产物"而非"我们的看法"，可作为 L1 输出。

## 4. L2 → L1 改写对照表（个股分析专用）

| 现状（L2，禁出） | 违规类型 | 改写为（L1/L0，可出） |
|---|---|---|
| 综合评级：强烈推荐 / 谨慎推荐 / 中性 / 观望 / 回避 | 宾语指向 + 主体指向 | **六维规则化评分**：`综合 X/100`（权重见 §5 口径表），并列出各维得分 |
| 选时结论：建仓期 / 持股期 / 减仓期 / 观望期 | 宾语指向 | **技术面状态描述**：`均线呈强空头排列（MA5<MA10<MA20<MA60）、MACD 死叉、RSI=28（超卖区间）` |
| 止损位 = X 元 | 宾语指向 | **支撑位 = X 元（数据源原生字段，距现价 Y%）**——不附加"跌破应止损"的指令 |
| 目标位 = 第一目标 X 元 / 第二目标 Y 元 | 时间指向 | **压力位 = X 元、MA250 = Y 元、区间高点 = Z 元**——只报位置，不报"目标" |
| 入场条件：站上 MA20 且 MACD 金叉后可考虑建仓 | 宾语指向 | **信号状态**：`当前未站上 MA20（现价 X < MA20 Y），MACD 处于死叉状态` |
| 执行建议：分批 / 等待确认 / 控制仓位 | 宾语指向 | **删除**。或改写为事件时点事实：`该事件于 MM-DD 公告，当日股价 -6.72%` |
| 不建议持有（高风险规则结论） | 宾语指向 | **规则命中事实**：`最近 3 期净利润连续为负（-X/-Y/-Z 万元，[报告期]）；收盘价 X 元低于 MA60=Y 元（[交易日]）`——只列规则与数值，不作结论 |
| G1 简报结论"不建议持有 / 超出分析能力" | 宾语指向 | `触发 G1 规则：最近 3 期净利润连续为负（-X/-Y/-Z 万元）、PE(TTM) 为负` |
| ST 修正评级：强烈推荐 / 谨慎推荐 / … | 宾语指向 + 主体指向 | **ST 条件清单**：`摘帽条件 X 已满足 / 未满足（依据：公告 MM-DD）` |
| 综合优先级：Top1 = A > Top2 = B | 宾语指向（隐含"先买谁"） | **固定口径得分排序**：`按 §5 口径表评分：A 68 分 > B 61 分 > C 55 分`，**必须附"非投资建议"标注** |
| 估值判断：低估 / 高估 | 主体指向（脱离阈值时） | **挂阈值**：`PE(TTM) 近三年分位 = 22%，按固定阈值（<30% 偏低）属偏低区间` |
| 是否值得中长期关注 | 主体指向 | 删除，或列为客观事实：`近 5 期 ROE 为 X%/Y%/Z%…（连续 3 期上升）` |
| 资金结论"主力持续流入，态度积极" | 主体指向 | `5 日主力净额 +X 万元、10 日主力净额 +Y 万元，方向一致为正` |
| 缺失即风险："因公告未获取到数据，该股存在未披露风险" / "财务数据缺失，经营透明度存疑" | 主体指向 + **未知当负面** | **覆盖度声明**：`未获取到数据（接口返回为空）。本次不参与评分`——缺失只说明覆盖度，不构成负面事实（铁律 12） |

> **对照表是开放清单**，遇到表中未列的措辞，回到 §2 三问测试自行判定，判定后把新条目补进本表。

## 4A. L1 扩展：条件性研究判断（2026-09-23 新增，唯一扩展档位）

> 允许输出"基于证据的条件性解释"（研究假设），但它是 L1 的**受限扩展**而非新档位：不满足以下任一条即整句删除，不得降格输出。

**五条硬约束（全部满足才可输出）**：

1. **事实支撑**：必须有 ≥2 条已发生的 L0 事实支撑；凭单一新闻、传闻或概念标签立假设的，禁出
2. **反证同句**：必须同句写出反证/失效条件（如"若下一报告期毛利率回升，则该解释需要下调"）
3. **置信度标注**：必须标注"置信度：高/中/低"（定义见 `event-analysis-rules.md` §6）
4. **逐句仍过三问测试**：出现时间指向（"后续将""有望"）、宾语指向（"可关注""建议跟踪"）、主体指向（"我们看好"）任一命中即禁出；条件假设写成确定预测的按 L2 删除
5. **数量与隔离**：每份报告最多 **2 条**；必须与 L0 公告事实**分栏**呈现（标"条件性解释，非事实"），不得混写进事实段落

**允许的表达**：

```text
毛利率连续 2 期下滑（-A%、-B%），同期原材料价格指数上行 C%（置信度：中）；
若下一报告期原材料价格回落而毛利率未回升，则该解释需要下调。
```

**禁止的表达**：

```text
毛利率下滑系原材料涨价所致，预计下季度将改善。（缺反证 + 时间指向，L2）
```

**适用范围**：基本面归因、事件与异动归因（`event-analysis-rules.md` §5.4）。技术面不用条件性表达（技术面只有 L0 数据 + L1 状态）。
