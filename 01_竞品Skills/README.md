# 竞品原始资料目录

## 目录

| 目录 | 含义 |
|---|---|
| `广发证券/` | 广发官方 ZIP、解压包和本地安装内容 |
| `国信证券/` | 国信官方 ZIP、解压包和 README |
| `中信建投-官网/` | 从 `skillhub.csc108.com` 官方下载接口取得的 8 个原始 ZIP 与解压内容 |
| `中信建投-WorkBuddy/` | 从 WorkBuddy 安装后只读归档的 8 个平台适配版 |
| `东方财富妙想/` | 妙想 MCP 安装文档与工具元数据 |
| `公开检索证据/` | 搜索和媒体报道的原始证据，只用于证明“曾经出现过什么” |
| `WorkBuddy/` | WorkBuddy 本地目录、安装链路与平台扫描说明 |

## 核心基本原则

1. **官网原始包**和**平台适配包**必须分开保存。
2. 原始 ZIP 不直接修改；解压内容用于阅读和对比。
3. 安装到本机或平台的版本单独标注，不能冒充官网原文。
4. 公开检索证据不是安装包，也不是最终结论。
5. 任何 ZIP 解压前先检查路径穿越、可执行文件和危险命令。
