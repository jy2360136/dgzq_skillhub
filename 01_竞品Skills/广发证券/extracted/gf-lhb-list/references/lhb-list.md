# 龙虎榜个股列表 字段速查

工具：`service_name=lhb` / `tool_name=lhb_aborttrade_market_date_get`
作用：获取指定交易日、指定市场上榜的异常交易个股列表及上榜原因。

CLI：`python scripts/cli.py --date <YYYYMMDD> --market <sh|sz>`

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `date` | integer | 是 | 交易日，格式 `YYYYMMDD`，如 `20260313`；须为交易日 |
| `market` | string | 是 | 市场，**必须小写**：`sh`=上海 / `sz`=深圳 |

> ⚠️ **大小写陷阱**：本工具 `market` 用**小写** `sh` / `sz`，与 F10（`SH`/`SZ` 大写）、估值（带前缀大写代码 `SZ000776`）不同。CLI 已对 `--market` 自动 `lower()`，手填 args 时务必小写。

## 返回结构

业务数据在 `data.data`，为一个数组，每个元素代表一只上榜个股；个股的多条上榜原因放在 `items[]` 数组里。

### 个股层字段

| 字段 | 说明 |
|------|------|
| `trdCode` | 交易代码 |
| `secuSht` | 证券简称 |
| `clsPrc` | 收盘价 |
| `dayChgRat` | 日涨跌幅（%） |
| `tnvVol` | 成交量 |
| `tnvVal` | 成交额（元） |

### 上榜原因层字段（`items[]`）

| 字段 | 说明 |
|------|------|
| `items[].rsnSht` | 上榜原因（简称） |
| `items[].rsnCode` | 上榜原因代码 |
| `items[].beginDate` | 统计区间起始日 |
| `items[].endDate` | 统计区间结束日 |

## 空值排查

数据为空时依次检查：

1. **日期是否交易日**：周末 / 节假日 / 非交易日无数据。
2. **`market` 是否为 `sh` / `sz`**：且必须小写。
3. **当日该市场是否存在上榜个股**：某些交易日某一市场可能无异动上榜。
4. **市场不明时**：分别查 `sh` 和 `sz` 两次，不要随意默认某一市场。

## 数据限制

优先查询单个交易日。需多日数据时拆分为多次单日请求，避免单次返回内容过长。
