# 个股综合分析报告模板

> **Agent 使用说明**：
> - 严格按照本模板格式输出，不得改变章节先后顺序或表格结构。六维模式不得删掉覆盖范围内的章节。专项模式删掉未覆盖维度的章节，其余章节从「一」连续编号。
> - 标注「必填」的节在六维模式下必须输出；「条件必填」满足触发条件时必须输出；「可选」有实质内容时才输出，无内容则整节省略。模板标题里的「必填」「条件必填」是执行标记，写入报告时删掉。
> - **覆盖范围由 SKILL.md Step 1 决定**：默认六维全覆盖；专项模式下**未覆盖维度整节省略**（不留空章节、不写「不构成任何判断」），只在报告头部声明"未查询（按您指定的范围）"。
> - 事实先行：每节开头先给核心事实句，再给数据支撑。
> - 禁止无依据结论：所有判断必须引用具体字段值。
> - 金额统一换算为**万元**，保留整数（如 85269700 元 → 8527万元）。
> - 技术指标必须标注**数据交易日**；财务表格必须标注**报告期**。
> - 技术面统一使用**当前数据源原生指标**（均线/ MACD / KDJ / 布林带 / RSI / 支撑压力位 / 主力持仓成本），不得出现数据源外的私有复合字段名。
> - 行情序列统一使用**前复权**，并在报告头部注明。
> - **区间连接符**：报告正文禁止用半角 `~` 或全角 `～`。日期、价格、估值、阈值、业绩预告的金额与同比幅度一律写「至」（`2023-09-24至2026-09-24`、`5.43至11.22`、`72.14至81.16亿元`、`同比+60%至+80%`）。数据源原文不得照抄。成对 `~` 会被 Markdown 渲染成删除线（两个波浪号之间划出一条中线）；复制后波浪号消失，`72.14~81.16`、`+60%~+80%` 会粘成 `72.1481.16`、`+60%+80%`。
> - **覆盖范围**：默认覆盖基本面、财务、技术面、资金、新闻、公告与事件。用户指定范围时，公告与事件仍要查，结果写入「公告与事件」章，不在标题或头部解释为什么要查。未覆盖维度只在头部写「未查询（按您指定的范围）」，禁止写成「无风险」，禁止再开一节。覆盖范围内取不到的写「未获取到数据」加原因。章节标题只写名称。过程说明和报告不写内部代号：安全网、已固定核查、无重大负面、未能核查、G0/G1/G2、NA、NOT_COVERED、SCORED、SAFETY_NET、NOT_APPLICABLE、IBS、VMA、DDE、串行单发，也不写仓库路径。
> - ⚠️ **合规出口必过**（铁律 11）：仅输出客观数据与规则化描述，**不得出现建议、预测、主观评价**。判定与改写对照见 `references/compliance-boundary.md`（唯一定义点）。本模板中已按合规要求改写，执行时不得改回"评级/止损位/目标位/执行建议"等旧写法。
