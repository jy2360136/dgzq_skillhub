# 技术分析通用规则（A股，与数据源无关）

本文档定义本 Skill 中所有技术面/资金面判断的**量化阈值**与**派生指标计算方法**，确保结论可复现、可追溯。

> **重要**：本文件描述的是 **A 股技术分析的通用规则**（均线/动量/布林带/形态/量价），**与具体数据源无关**。换数据源时**不需要**改本文件，只需保证新数据源能提供"收盘价、最高价、最低价、成交量、MA_N、MACD、KDJ、RSI、布林带、支撑压力位、主力资金净额"等基础字段即可。
>
> **盘中交易日口径（2026-10-08 实测补充，与数据源无关）**：当取数发生在交易日盘中（当日 K 线未走完）时，**技术指标（MA/MACD/KDJ/RSI/BOLL/区间涨跌幅/量能）一律以"最近完整交易日"的收盘序列计算**，并在报告的技术表头标注该完整交易日；当日盘中价单独在报告头部"数据截止"中以"盘中 + 精确时点"标出，不混入指标序列。理由：未走完的 K 线会使当日 MA/MACD 交叉判定与量能强度随取数时刻漂移（同一交易日不同时点可得出不同结论），破坏 L1 可复现性。同一报告中至少有一处"现价"用于关键位对比时，明确写出所用价及其时点。

所有原生字段来自当前数据源的"实时行情、日行情、技术指标、资金流向"等表（具体表名见 `references/data-source-config.md` 与 `references/data-source-queries.md`）。

## 一、派生指标计算（唯一允许的4类计算）

除以下 4 类外，禁止自行发明指标。全部由原始数据直接计算，结果需在报告中注明计算方法。

### 1. 日内收盘强度（IBS）

```
IBS =（收盘价 − 最低价）/（最高价 − 最低价）× 100
```

数据来源：`股票日行情` 当日 `收盘价（元）`、`最高价（元）`、`最低价（元）`。

| 区间 | 判断 |
| --- | --- |
| ≥ 70 | 强势收盘，多方掌控尾盘 |
| 30 ~ 70 | 中性 |
| ≤ 30 | 弱势收盘，空方掌控尾盘 |
| = 0 | 收于当日最低，极弱 |
| = 100 | 收于当日最高，极强 |

> 单日 IBS 意义有限，需结合**连续 3-5 日** IBS 分布，看收盘强弱是否连续处于同一区间。

### 2. MA 乖离率

```
MA_N乖离率 =（收盘价 − MA_N）/ MA_N × 100
```

数据来源：`股票技术分析` 的 `收盘价简单移动平均MA_N(元)`。

| 区间 | 判断 |
| --- | --- |
| 0 ~ 5 | 贴近均线，健康 |
| 5 ~ 15 | 偏离偏大，短期偏强但防回抽 |
| > 15 | 短期过热，回抽概率上升 |
| −5 ~ 0 | 轻微跌破，观察 |
| < −5 | 明显跌破该均线，趋势转弱 |

### 3. N 日区间涨跌幅

```
N日涨跌幅 =（最新收盘价 / N个交易日前收盘价 − 1）× 100
```

数据来源：`股票日行情`（**必须使用前复权序列**）。
标准观察窗口：1日、5日、10日、20日、60日、250日。

| 组合形态 | 判断 |
| --- | --- |
| 1日/5日/20日同向为正 | 趋势连续向上 |
| 1日/5日/20日同向为负 | 趋势连续向下 |
| 短期为正、20日为负 | 下跌趋势中的反弹 |
| 短期为负、20日为正 | 上升趋势中的回调 |
| 各周期方向散乱 | 动量分化，无明确趋势 |

### 4. 量能强度

```
量能强度_N =（当日成交量 − VMA_N）/ VMA_N × 100
```

数据来源：`股票技术分析` 的 `成交量简单移动平均VMA_N(万股)` + `股票日行情` 的 `成交量（万股）`。

| 组合 | 判断 |
| --- | --- |
| 量能强度 > 0 且价格创区间新高 | 放量突破，信号可靠性高 |
| 量能强度 < 0 且价格回调 | 缩量回踩：量能强度为负，价格较前高回落 |
| 量能强度 > 0 且价格下跌 | 放量下跌，警惕出货 |
| 量能强度 < 0 且价格上涨 | 缩量上涨，动能不足 |

## 二、趋势结构信号（均线体系）

数据来源：`股票技术分析`。

| 信号 | 判定条件 | 含义 |
| --- | --- | --- |
| 强多头排列 | MA5 > MA10 > MA20 > MA60 | 中短期趋势一致向上 |
| 弱多头排列 | MA5 > MA10 > MA20，但 MA20 < MA60 | 短期转强，中期仍待修复 |
| 均线纠缠 | 各均线两两**相对差异** < 1%（相对百分比，非绝对价差；高价股与低价股不得用同一绝对价差标准） | 各均线相对差异 < 1%，方向不明 |
| 弱空头排列 | MA5 < MA10 < MA20，但 MA20 > MA60 | 短期转弱，中期未破 |
| 强空头排列 | MA5 < MA10 < MA20 < MA60 | 中短期趋势一致向下 |
| 长期趋势向下 | MA60 < MA250 | 大级别走弱，反弹需降权 |
| 长期趋势向上 | MA60 > MA250 | 大级别走强，回调可承接 |

补充：比较 `收盘价` 与各均线，判断价格位于均线系统的哪一层。

## 三、动量指标信号

### 3.1 MACD

数据来源：`股票技术分析` 的 `指数平滑异同平均DIFF`、`DEA`、`MACD`（柱）。

> **柱体口径注（2026-09-23 补齐）**：不同数据源的柱体定义可能是 `DIFF−DEA` 或 `2×(DIFF−DEA)`，两者数值不可混用。每次取数须先确认当前数据源的柱体口径（可抽样用 `2×(DIFF−DEA)` 与返回值比对验证），报告口径与本地计算口径保持一致；口径不明确时以 DIFF/DEA 交叉与零轴位置为主要依据，柱体只作扩张/收缩的**趋势方向**判断，不引用柱体绝对值。

| 信号 | 判定条件 | 含义 |
| --- | --- | --- |
| 金叉 | DIFF 上穿 DEA（前一日 DIFF<DEA，当日 DIFF>DEA） | 短期动能转多 |
| 死叉 | DIFF 下穿 DEA | 短期动能转空 |
| 零轴上方金叉 | DIFF>0 且金叉 | 强势中的再加速，信号最强 |
| 零轴下方金叉 | DIFF<0 且金叉 | 弱势反弹，需量能配合 |
| 红柱扩张 | MACD>0 且逐日放大 | 多头动能增强 |
| 红柱收缩 | MACD>0 且逐日缩小 | 多头动能衰减，警惕转势 |
| 绿柱扩张 | MACD<0 且绝对值逐日放大 | 空头动能增强 |
| 绿柱收缩 | MACD<0 且绝对值逐日缩小 | 空头动能衰减，接近企稳 |

### 3.2 RSI

数据来源：`股票技术分析` 的 `相对强弱指标RSI`。

| 区间 | 判断 |
| --- | --- |
| > 80 | 严重超买，回调风险高 |
| 70 ~ 80 | 超买，强势但不宜追高 |
| 50 ~ 70 | 多方占优，健康区间 |
| 30 ~ 50 | 空方占优，弱势区间 |
| 20 ~ 30 | 超卖，存在反弹机会 |
| < 20 | 严重超卖，极端弱势（或加速下跌） |

> RSI 在强趋势中可长期钝化于高位/低位，**不可单独作为反转依据**，必须与均线、量能交叉验证。

### 3.3 KDJ

数据来源：`股票技术分析` 的 `KDJ随机指标K值`、`D值`、`J值`。

| 信号 | 判定条件 | 含义 |
| --- | --- | --- |
| 金叉 | K 上穿 D | 短期转多 |
| 死叉 | K 下穿 D | 短期转空 |
| 超买 | K>80 且 D>80 | 短期高位 |
| 超卖 | K<20 且 D<20 | 短期低位 |
| J 极端超买 | J > 100 | 极强，随时可能回落 |
| J 极端超卖 | J < 0 | 极弱，随时可能反弹 |

## 四、布林带信号

数据来源：`股票技术分析` 的 `布林线中轨MID`、`上轨UPPER`、`下轨LOWER`。

| 位置 | 判断 |
| --- | --- |
| 收盘价 > UPPER | 突破上轨，强势但需防回抽 |
| MID < 收盘价 < UPPER | 中轨上方运行，多头占优 |
| 收盘价 ≈ MID | 多空平衡 |
| LOWER < 收盘价 < MID | 中轨下方运行，空头占优 |
| 收盘价 < LOWER | 跌破下轨，弱势或超跌 |

**带宽信号**：`带宽 =（UPPER − LOWER）/ MID × 100`

- 带宽处于近期低位（明显收窄）→ 只记录波动收窄；方向另看量能与均线，不由带宽单独给出
- 带宽快速扩张 → 趋势加速或情绪释放

## 五、关键位与成本信号

数据来源：`股票技术分析` 的 `支撑位`、`压力位`、`主力持仓成本`。

| 信号 | 判定条件 | 含义 |
| --- | --- | --- |
| 距压力位空间 | `（压力位 − 现价）/ 现价 × 100` | < 3% 上涨空间受限；> 10% 空间充裕 |
| 距支撑位空间 | `（现价 − 支撑位）/ 现价 × 100` | < 3% 缓冲很薄，破位风险大 |
| 主力浮盈 | 现价 > 主力持仓成本 | 主力有利润垫，抛压意愿可能上升 |
| 主力浮亏 | 现价 < 主力持仓成本 | 主力被套，存在护盘动力也可能是压力源 |
| 成本上移 | 主力持仓成本逐日抬升 | 主力仍在吸筹/加仓 |
| 成本下移 | 主力持仓成本逐日下降 | 主力减仓或换手 |

> 结合 `股票日行情` 的多日数据，观察 `支撑位 / 压力位 / 主力持仓成本` 三者的**变化方向**，比单日绝对值更有信息量。

## 六、资金面信号

数据来源：`个股资金流向`、`A股实时资金流向`、`个股融资融券`、`陆股通持股`、`股东户数`。

| 信号 | 判定条件 | 含义 |
| --- | --- | --- |
| 主力持续流入 | 主力净额连续 ≥ 3 日为正是 | 资金持续看好 |
| 主力持续流出 | 主力净额连续 ≥ 3 日为负 | 资金持续撤离 |
| 短期资金转强 | 5日主力净额 > 0 且 10日主力净额 < 0 | 5日主力净额为正，10日主力净额为负 |
| 短期资金转弱 | 5日主力净额 < 0 且 10日主力净额 > 0 | 5日主力净额为负，10日主力净额为正 |
| 资金比偏高 | `资金比(%)` 绝对值 > 10 | 主力行为对股价影响显著 |
| 大单与超大单背离 | 超大单净额为负、大单净额为正（或反之） | 主力内部意见分歧 |
| 杠杆加仓 | 融资净买入额持续为正且融资余额抬升 | 杠杆资金看多 |
| 杠杆去化 | 融资余额持续下降 | 杠杆资金撤出，波动放大 |
| 外资增持 | 持股占流通股本比例环比抬升 | 持股占流通股本比例较上期上升 |
| 外资减持 | 持股占流通股本比例环比下降 | 持股占流通股本比例较上期下降 |
| 筹码集中 | 股东户数下降 + 户均持股上升 | 筹码向少数账户集中，通常偏多 |
| 筹码分散 | 股东户数上升 + 户均持股下降 | 筹码分散，通常偏空 |

## 七、行业与市场校准信号

数据来源：`指数日行情`、`市场涨跌停家数`。

| 信号 | 判定条件 | 含义 |
| --- | --- | --- |
| 跑赢行业 | 个股N日涨幅 > 行业指数N日涨幅 | 个股强于行业，具备 alpha |
| 跑输行业 | 个股N日涨幅 < 行业指数N日涨幅 | 个股弱于行业，需找原因 |
| 行业顺势 | 行业指数同期上涨 | 行业景气提供支撑 |
| 行业逆势 | 行业指数同期下跌 | 行业景气拖累个股 |
| 市场广度好 | 上涨家数 / 成分股家数 > 60% | 赚钱效应好，可对个股结论加权 |
| 市场广度差 | 上涨家数 / 成分股家数 < 40% | 赚钱效应差，需对个股结论降权 |

> 校准规则：**个股结论与行业/市场同向时可信度提高；明显背离时必须明确指出并给出解释**，不得忽略。

## 八、综合评分规则（原「综合评级规则」已废除）

> ⚠️ **评级体系已废除**（铁律 11，宾语指向+主体指向违规）。本节只定义**技术面维度的评分阈值**，供 `scoring.md`（评分口径唯一定义点）引用；权重、缺失处理与覆盖率以该文件为准。
> 本节输出的是**规则产物（分数）**，不是"我们的评级"，报告中不得附加"高分即值得买"类引导语。

### 8.1 技术面·趋势结构（满分 20）

| 均线排列状态 | 得分 |
| --- | --- |
| 强多头排列（MA5>MA10>MA20>MA60 且 MA60>MA120） | 20 |
| 多头排列（MA5>MA10>MA20>MA60，且不满足强多头条件） | 15 |
| 弱多头排列（MA5>MA10>MA20，**但 MA20<MA60**） | 15 |
| 均线纠缠（各均线两两**相对差异** <1%） | 10 |
| 弱空头排列（MA5<MA10<MA20，**但 MA20>MA60**） | 5 |
| 空头排列（MA5<MA10<MA20<MA60，且不满足强空头条件） | 5 |
| 强空头排列（MA5<MA10<MA20<MA60 且 MA60<MA250） | 0 |

> **与 §二 的映射（2026-09-23 补齐，消除口径灰区）**：§二 定义**五态**（强多头 / 弱多头 / 均线纠缠 / 弱空头 / 强空头），本节原表只写"多头排列 / 空头排列"两个不带强弱限定词的档位，导致"弱多头排列（MA5>MA10>MA20 但 MA20<MA60）"与"弱空头排列（MA5<MA10<MA20 但 MA20>MA60）"**无对应档位**、需临场判断。现按 §二 五态 ↔ 本节五档**一一对应**显式展开：**弱多头排列与多头排列同记 15 分，弱空头排列与空头排列同记 5 分**（分差只体现在"中期均线是否已修复"，不足以跨越档位）。判定顺序：先判强多头 → 再判强空头 → 再判均线纠缠（相对差异 <1%）→ 最后按 MA5/MA10/MA20 排列方向 + MA20 与 MA60 的相对位置判多头/弱多头/空头/弱空头。

### 8.2 技术面·动量与位置（满分 15，各 5 分）

| 子项 | 5 分 | 3 分 | 0 分 |
| --- | --- | --- | --- |
| MACD | 金叉且红柱扩张 | 金叉但红柱收缩 / 死叉但绿柱收缩 | 死叉且绿柱扩张 |
| KDJ 与 RSI 位置 | RSI 30~70（且 K、D 均在 20~80） | RSI>70 或 RSI<30，或 K、D 同时 >80 或同时 <20 | RSI>85 或 RSI<15 |
| 布林带位置 | 中轨上方且未破上轨 | 中轨附近（收盘价在 MID±1% 内） | 中轨下方（含下轨附近、跌破下轨） |

> **KDJ/RSI 冲突取值口径（此前未定义，2026-09-22 补齐）**：两者状态不一致时，**以更偏离中性的一档为准**，即判定优先级 `0 分 > 3 分 > 5 分`。例：RSI=33.8（中性区）但 K=4.0、D=7.6（同时 <20，超卖）→ 记 **3 分**。
> 副说明：J 值（=3K−2D）波动大、穿 0 频繁，**不单独用于降档**；仅在 K、D 已同时处于极端区（>80 或 <20）时与 K/D 同档处理，避免与 K/D 重复计分。

> **布林带档位判定口径（2026-09-30 补齐，消除口径灰区，分值未变）**：判定轴是"收盘价相对**中轨**的位置"，MID±1% 是唯一的中间带——收盘价 > MID×(1+1%) 记 **5 分**（含突破上轨情形，突破上轨时另按 §四 标注"强势但需防回抽"）；|收盘价 − MID| ≤ MID×1% 记 **3 分**；收盘价 < MID×(1−1%) 记 **0 分**。
> 原 0 分档写作"下轨附近或跌破下轨"，未覆盖"中轨下方、但距下轨尚有距离"的情形（实测中国平安 601318，2026-09-30：收盘价 53.29 低于中轨 54.414 达 2.06%，既不在 MID±1% 内、距下轨 51.813 也还有 2.85%，按原表无档可落）。现明确 0 分档 = **中轨下方的全部情形**，与 §四"中轨下方运行，空头占优"的定性一致。

> 上述阈值固定，任何人按同一份数据算出的分数一致（L1 规则化描述）。

### 8.5 资金面评分细则（满分 15，三项各 5 分）

| 子项 | 5 分 | 3 分 | 0 分 |
| --- | --- | --- | --- |

> **资金连续性判定口径（2026-09-30 补齐，消除口径灰区，分值未变）**：判定对象是"截至最新交易日的**最后一段**连续同向"，并**回看其之前的一段**——两段中任一段长度 ≥3 日，即按**该段方向**归档；只有两段长度均 <3 日才记 3 分（交替）。
> 理由：原表述在"连续多日同向、最新一日刚反向"时无档可落（实测中国平安 601318：2026-09-30 主力净额 +4,676 万元为单日净流入，其前一段是 09-23 至 09-29 的 4 日净流出；按"连续净流入 ≥3 日"不成立、按"无 3 日以上同向"也不成立）。上例中前一段为 4 日净流出 ≥3 日，故按**连续净流出**归档，记 0 分。

### 8.6 事件与消息面评分细则（满分 10）

按事件表逐条赋权（量级：涉及金额或影响面 ≥50 亿元、或涉及公司治理全公司层面 = 3；10~50 亿元 = 2；<10 亿元 = 1），得分公式：

```
得分 = 10 ×（Σ利好权重 − Σ利空权重）/ 12，结果裁剪到 [0, 10]
```

- 中性事件权重为 0，不参与计算
- 同一事件在新闻/公告/事件表重复出现时**只计一次**（合并去重）
- 传闻与未经公告证实的内容**不计入评分**，仅在报告"传闻与未经证实信息"栏以 L0 事实呈现

## 九、突破有效性确认、信号置信度与失效条件（2026-09-23 自方法论 v2 合并）

### 9.1 突破有效性确认（5 项清单）

判定"突破"有效前逐项检查，**至少满足 3 项**才可输出"突破有效"状态标签，否则写"突破待确认"：

1. 是否突破区间高点或关键位（压力位 / 前高 / 布林上轨）
2. 收盘是否维持在突破位上方（盘中冲高不算）
3. 后续至少一个有效交易日未回落失守
4. 成交量是否持续（多日量能强度 > 0），而非单日异常
5. 行业指数和市场环境是否同步（同向突破可信度更高）

**红线**："放量上涨、缩量回调"是**形态标签，不是原因结论**；不得用单日放量认定"主力吸筹""洗盘""出货"（主体指向违规，见 `compliance-boundary.md` §4）。

### 9.2 信号置信度

| 等级 | 条件 |
| --- | --- |
| 高 | 多项独立指标同向，且行业/市场同步，数据完整 |
| 中 | 主要指标同向，但缺少行业、资金或事件验证 |
| 低 | 单一指标、单日数据，或指标相互冲突 |

- 指标分化（如 RSI 与 KDJ 方向不一致）时输出"指标分化"，不得强行解释成同一方向
- **信号置信度不是收益概率**，不得写成"高置信度信号，预计上涨"（时间指向违规）
- 单日金叉只标记为"出现交叉状态"，不写成趋势反转；RSI 高低位在强趋势中可长期钝化，不单独作为反转依据

### 9.3 失效条件（命中时必须下调技术结论置信度）

停牌复牌、除权除息、极端涨跌停、数据日期不一致、成交量口径不明、分钟线不完整、指标由不同复权序列计算、行业分类变化。

### 9.4 资金面措辞边界

主力净额、大单、融资、陆股通均为**数据源定义下的资金流向指标，不等于真实资金主体意图**：

- 允许：`5 日主力净额为正、10 日主力净额为负，短中期方向分化`
- 禁止：`主力持续看多、机构正在吸筹、资金必然撤离`（主体指向 + 时间指向违规）

资金数据必须注明日期、计算窗口和适用范围。
