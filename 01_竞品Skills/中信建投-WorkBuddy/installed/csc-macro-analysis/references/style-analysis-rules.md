# 市场风格分析规则

## 1. 风格分类

默认观察：

- 大盘/小盘；
- 成长/价值；
- 周期/消费/防御；
- 红利/高股息/低波动；
- 科技制造/传统行业；
- 高估值/低估值；
- 高波动/低波动。

必须以明确风格指数、组合或成分股口径为准，不用自然语言标签替代定义。

## 2. 风格相对强弱

对每类风格计算：

- 1日、5日、20日、60日相对收益；
- 成交额和换手变化；
- 成分股上涨比例；
- 创新高与创新低；
- 相对基准指数的超额收益；
- 持续性和波动。

相对收益定义：

```text
风格相对收益 = 风格组合区间收益 - 基准指数区间收益
```

区间收益的累计口径是**复利**：

```text
区间收益 = ∏(1 + 各交易日涨跌幅 / 100) − 1
```

不得用算术求和替代（单日窗口两种算法同值，只在多日窗口暴露差异）。窗口起止写「起算收盘日 → 末日收盘」：末 N 行累计的起算收盘日是序列第 `len − N − 1` 行那天，不是末 N 行的首日。相对收益必须用**同窗口**的基准指数相减，不得拿两条风格指数直接相减冒充。

## 3. 占优风格判定

5日和20日相对收益为正，且至少两个相邻观察窗口保持相对优势，标为阶段性占优。只有单日涨幅领先时，标为短期强势，不得标成阶段性占优。成分股上涨比例、成交额或换手、均线、事件解释取到时作旁证，取不到时不因此改判。

## 4. 风格轮动

轮动判断必须区分：

- 真实相对强弱切换；
- 指数权重造成的表观变化；
- 单一权重股带动；
- 低基数反弹；
- 高波动主题交易。

“从A切换到B”必须有至少两个窗口的相对收益和广度证据。

## 5. 风格拥挤与失效

可观察：估值分位、成交占比、换手、集中度、融资余额和连续上涨天数。拥挤只表示交易集中或估值偏高，不等于必然回落。

失效条件包括：相对收益转负、广度下降、成交萎缩、行业逻辑证伪、政策或宏观环境改变。
